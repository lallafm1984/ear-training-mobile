# MelodyGen 2.0 콘텐츠 오픈 범위 (무료 / Pro)

2.0 업데이트에서 추가된 모든 콘텐츠의 무료·Pro 구분표. 코드 기준은 `src/lib/contentConfig.ts`의
`CONTENT_CATEGORIES[].freeMaxLevel`(무료 사용자가 열 수 있는 난이도 수)과 `NEW_CONTENT_DIFFICULTIES`이며,
요금제 화면 비교표(`PaywallScreen`)는 이 값에서 자동 생성된다.

## 원칙

- 무료 사용자는 각 카테고리의 **앞쪽 1~3단계**를 쓸 수 있고, 그 뒤 단계는 Pro다 (잠금 아이콘 + 시작 버튼이 Pro 안내 → 요금제 화면).
- **2.0에서 추가된 난이도는 모두 기존 무료 범위 뒤에 붙으므로 Pro 전용**이다. 무료 범위는 1.1.x와 똑같아 기존 무료 사용자가 쓰던 단계가 잠기는 일은 없다.
- 새 난이도는 난이도 목록과 홈 카테고리 카드에 **NEW** 배지로 표시한다.
- 레벨 테스트 추천은 무료 사용자에게 Pro 단계를 자동 선택하지 않는다 (`CategoryPracticeScreen`의 freeMaxLevel 가드). 레벨 테스트·입문 코스·모의시험 프리셋은 1.1.x와 같은 난이도만 사용한다.
- 2성부 받아쓰기는 1.1.x와 같이 Pro 전용(freeMaxLevel 0)이다.

## 카테고리별 범위

| 카테고리 | 무료 | Pro | 2.0 추가 콘텐츠 (전부 Pro) |
|---|---|---|---|
| 마디 받아쓰기 (barMelody) | 1~3단계 | 1~6단계 | — |
| 선율 받아쓰기 (melody) | 초급 1~3 | 초급~고급 9단계 | — (복합박자 둘잇단·다양성 개선은 전 단계 적용) |
| 리듬 받아쓰기 (rhythm) | 1~2단계 | 1~6단계 | — |
| 음정 듣기 (interval) | 1~2단계 | 1~6단계 | **5단계** 화성 음정(동시 울림), **6단계** 복합음정(9~13도) |
| 화성 듣기 (chord) | 1단계 | 1~4단계 | **4단계** 3화음 전위(제1·제2전위) |
| 화성 진행 (progression) | 1단계 | 1~7단계 | **5단계** 종지 세분화(PAC/IAC/반/기만), **6단계** 기능 진행(ii6·V7·전위), **7단계** 로마숫자 화음 판별 |
| 조성 판별 (key) | 1단계 | 1~3단계 | — |
| 2성부 받아쓰기 (twoVoice) | 잠금 | 1~4단계 | — (베이스 리듬 변형·종지 개선은 Pro 범위 안) |
| 음계·선법 듣기 (scale) | 1~2단계 | 1~5단계 | **5단계** 상행·하행(가락단음계 하행형) |
| 리듬 탭 (rhythmTap) | 1~2단계 | 1~6단계 | **5단계** 3/4박자, **6단계** 6/8박자 |
| 모의시험 | 기본 프리셋 | 전체 | — |

전 단계에 공통 적용된 품질 개선(무료 포함): 화성진행·종지 재생의 4성부 성부 배치(병행 금지·이끔음 상행·완전 정격종지),
트라이톤 라벨·해설 교정, 선율·2성부 생성 다양성, 복합박자 둘잇단.

## 기존 사용자 데이터 보존

- 학습 데이터 키는 1.1.x와 같은 `@melodygen_<종류>_<userId>` 형식이다 (`localDataKey`). 연습 기록·실력 프로필·마스코트 EXP·시험 기록의 저장 형태도 바뀌지 않았다.
- 2.0에서 추가된 키(게스트 `_guest`, 오답노트, 레벨 테스트, 입문 코스, 리마인더)는 새로 생기기만 한다. 게스트 → 로그인 이관은 병합(merge)이며 계정 데이터를 덮어쓰지 않는다.
- 새 난이도는 id가 추가될 뿐 기존 id·순서는 그대로라, 저장된 기록의 `difficulty`가 무효가 되지 않는다. 알 수 없는 id는 통계에서 그대로 집계되고 라벨은 id로 대체 표시된다.
- 회귀 테스트: `src/__tests__/localProfileStorage.test.ts` "기존 사용자 데이터 보존", `src/__tests__/computeStats.test.ts` "알 수 없는 난이도 id".
